📅 **November 18, 2026:** 14:00–18:00

## About the course

The course introduces the foundations of language modeling, neural networks, embeddings, Transformers, and modern LLMs.
It then explores chatbots, prompt engineering, reasoning models, multimodality, RAG, tool use, AI agents, and the opportunities and challenges of AI.
The course concludes with a **hands-on data analysis session using ChatGPT**, covering data exploration, cleaning, visualization, machine learning, and interpretation of results.
